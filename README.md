## Features

- User Authentication
- Room Based Chat
- Multi User Rooms
- Real-Time Messaging
- Typing Indicators
- Media Sharing
- Message Deletion
- Room Access Control
- Responsive UI

## Tech Stack

- Python
- Django
- Django Channels
- WebSockets
- HTML
- CSS
- JavaScript
- SQLite
